
# Filmstock2ELF
This is a backend for the [Filmstock](https://github.com/cdev-eloper/Filmstock) programming language.
It takes Filmstock IR, generated by the official compiler, and compiles it down into a native
ELF64 Linux executable. The high-level features (lists, etc.) as well as the Raylib bindings
are accomplished via a language runtime, written in C. The compiler uses FASM to encode x86-64 instruction.
The provided makefile will compile the 3D renderer IR `prg/3d_renderer.fs` as well as the runtime
and link them together.

## Requirements
These are all available in every mainstream package repository.

- [`Python>3.10`](https://www.python.org/downloads/)
- [`FASM`](https://flatassembler.net/)
- `GCC` or `Clang`
